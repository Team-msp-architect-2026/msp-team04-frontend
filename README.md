# 📱 MoMent Frontend

> React Native 기반 모바일 앱  
> 사용자 맞춤 추천, 예약, 지도 기반 탐색을 제공하는 클라이언트

---

## 📌 Overview

MoMent Frontend는 사용자가 자녀 정보를 입력하고  
교육·돌봄 프로그램을 추천받고, 예약까지 진행할 수 있는 모바일 애플리케이션입니다.

---

## ⚙️ Tech Stack

- **Framework**: React Native (Expo)
- **Language**: JavaScript / TypeScript
- **State Management**: (사용하면 추가 - 예: Context / Redux)
- **API Communication**: REST API (Spring Boot Backend)
- **Map**: Kakao Map SDK
- **Auth**: Kakao OAuth 2.0

---

## 🧩 주요 기능

- 👤 자녀 프로필 입력 UI
- 🎯 맞춤 추천 리스트
- 🗺️ 지도 기반 탐색 (카카오맵)
- 🎟️ 예약 및 결제 화면
- 🔔 알림 UI
- 💬 커뮤니티 화면

---

## 🚀 Getting Started

### 1️⃣ Clone
```bash
git clone https://github.com/your-repo/frontend.git
cd frontend
```

### 2️⃣ Install
```bash
npm install
```

### 3️⃣ Run
```bash
npx expo start
```
